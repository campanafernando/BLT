# Contracts — API and clients

Verified 2026-11-12 against `blt-project@7956a12`.

## Source of truth

| Artifact | Role | Who writes it |
|---|---|---|
| `blt-project/api/schema.yaml` | OpenAPI 3, generated by `drf-spectacular` (`make schema` = `--validate --fail-on-warn`) | generated |
| `blt-project/web/src/lib/types.ts` | TypeScript contract of the React client | **by hand**, against the schema |
| `blt-project/web/src/lib/api.ts` | the only code that calls `fetch`: token handling, single-flight refresh, error mapping | by hand |
| `blt-project/web/src/features/<area>/api.ts` | endpoint paths and payloads; calls `apiFetch` | by hand |

There is no code generator for the client. A contract change updates **both** the schema and
`types.ts`, in the same delivery.

## Endpoints (prefix `/api/v1/`)

| Area | Paths |
|---|---|
| Auth | `auth/token/`, `auth/refresh/`, `auth/me/`, `auth/users/` (id and names only) |
| Tasks | `tasks/`, `tasks/summary/`, `tasks/<id>/`, `tasks/<id>/complete/`, `…/reopen/`, `…/assign/` |
| Specs | `specs/` (body: `issue_url` xor `subject`; `Spec.source` is `issue` or `subject`), `specs/config/` (only `ai_enabled`, `publish_enabled`), `specs/<id>/`, `…/publish/`, `…/tasks/` |
| Docs | `api/schema/`, `api/docs/` |
| HTMX client | `app/`, `app/rows/`, `app/tasks/`, `app/tasks/<id>/complete|reopen|delete/` (HTML, not part of the JSON contract) |

One `APIView` per URL, on purpose (see `decisions.md`, D3). Pagination is `page` + `page_size`
(default 10).

## Errors

DRF shape: `{"detail": "..."}` or `{"field": ["message", ...]}`. Services raise Django exceptions (the one plain exception is `SpecAlreadyPublishedError`, 409);
`core/exceptions.py` converts them. `GET /auth/users/` returns the `UserBrief` schema. The React client reads both shapes in `lib/api.ts::toError`.
Do not invent a third shape.

Status codes that carry meaning: 404 for a task or spec the caller may not see, 403 for
creator-only delete, 409 for a second publish, 502/503 for tracker or provider failures
(`spec-flow.md`), 429 from throttles.

## Authentication

| Client | Mechanism |
|---|---|
| React | JWT, access 30 min, refresh 7 days with rotation and blacklist; tokens in `localStorage` (documented trade-off) |
| HTMX | Django session with CSRF |

Throttles: `anon` 20/min, `user` 120/min, `login` 10/min, `spec` 10/h (`POST /specs/` only),
`spec_publish` 30/h. Source: `api/config/settings.py`.

## Procedure: change the contract

1. Write the service test and the endpoint test first (80% coverage floor).
2. Change the service, then the view/serializer; give every view an explicit `@extend_schema`.
3. `make schema` in `blt-project` must pass with no warning.
4. Update `web/src/lib/types.ts` and the feature `api.ts` / hooks.
5. If the HTML client shows the data, update `hypermedia/` through the same service.
6. `make check`, then a browser pass with no console warning.
7. Announce a breaking change to the user before making it.
