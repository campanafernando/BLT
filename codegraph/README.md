# CodeGraph — BLT

One independent index per project, never one index over both. Indexes live in each project's
`.codegraph/` directory (git-ignored) and are not committed.

| Server | Index of |
|---|---|
| `codegraph-api` | `blt-project/api` |
| `codegraph-web` | `blt-project/web` |

The orchestrator itself is not indexed. `blt-project/` is an independent Git repository.

## Prepare

```sh
bash .opencode/bin/codegraph-mcp.sh api   # creates the index if missing, then serves it
```

The launcher runs `codegraph init` and `index` only when `.codegraph/codegraph.db` is missing.
Refresh an existing index with `codegraph sync blt-project/api` (incremental); do not re-index
everything every session.

After the FEFO adoption (`docs/fefo/ADOPTION.md`) this file is regenerated by `./bin/fefo sync`,
the servers run `codegraph serve --mcp --path <repo>` directly, and `./bin/fefo index` refreshes both.

## Query

Use the `codegraph-api` or `codegraph-web` server for that project; each is already bound to its
own path, so no `projectPath` argument is needed. CodeGraph does not index Markdown: use
`docs/vault/` for rules, contracts and decisions.
